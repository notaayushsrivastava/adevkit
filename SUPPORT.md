# Support & Troubleshooting

Need help using **adevkit**? Here are the fastest ways to find answers:

## 1. Documentation
Browse the full user guide, installation instructions, and CLI reference at:
- [https://docs.adevkit.aayushsrivastava.com](https://docs.adevkit.aayushsrivastava.com)

## 2. Quick Diagnostics
Before opening an issue, run the built-in diagnostics command to check your Python, `uv`, Git, Cargo, and Node.js toolchains:

```bash
adevkit info
adevkit check-update
```

## 3. Community & Bug Reports
- **Questions & Ideas**: [GitHub Discussions](https://github.com/notaayushsrivastava/adevkit/discussions)
- **Bug Reports & Feature Requests**: [GitHub Issues](https://github.com/notaayushsrivastava/adevkit/issues/new/choose)
- **Security Issues**: Follow [SECURITY.md](SECURITY.md) (do not open public issues for security vulnerabilities)
- **Direct Contact**: [aayush@aayushsrivastava.com](mailto:aayush@aayushsrivastava.com)
