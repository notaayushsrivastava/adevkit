04 · SECURITY

Keys stay encrypted on your machine.

Store API keys and global toolchain defaults in ~/.adevkit/vault.json without plaintext leaks.

Windows DPAPI ProtectionHardware Protected

On Windows, sensitive keys (*_key, *_token, *_secret) are encrypted via native CryptProtectData bound to your user account.

POSIX Salted Key DerivationmacOS & Linux

On macOS and Linux, secrets are encrypted with a machine-and-user derived key and masked by default in CLI and Studio outputs.
